Comandos para enviar alteracoes ao GitHub

(Codigo digitado)

git status
git add .
git status
git commit -m "Descreva a alteracao"
git push

Exemplo para adicionar o arquivo de anotacoes:

git add "01-Vaamond/srvgabrielo.txt"

(Resultado do codigo)

git status mostra os arquivos alterados. git add prepara o arquivo para o commit, git commit registra a alteracao no repositorio local e git push envia os commits para o GitHub.

(Alteracao feita por mim no codigo)

Troque "caminho-do-arquivo" pelo caminho do arquivo que deseja enviar e "Descreva a alteracao" por uma mensagem curta para o commit.

(Confirmacao e salvamento do codigo)

git status
git push

Confira no GitHub se o arquivo e a alteracao aparecem no repositorio.

(Pequeno resumo)

Sequencia de comandos para selecionar um arquivo, registrar a alteracao no Git e envia-la ao repositorio remoto no GitHub.
